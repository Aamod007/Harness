### Typography Scale

- **Display & UI Copy**: `"DM Sans", -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`
  - Headers: 600 weight, tight letter-spacing (`-0.02em`).
  - Body: 400 & 500 weight, 1.4–1.6 line-height.
- **Data Tokens, Telemetry & Code**: `"DM Mono", ui-monospace, SFMono-Regular, Menlo, monospace`
  - Applied strictly to: IPv4 addresses, SHA-256 hashes, Unix timestamps, mathematical formulas, row counts.
  - Tabular numerals enabled (`font-variant-numeric: tabular-nums`).

### Elevation, Radii & Depth

- `--radius-sm`: `4px` (Tags, chips, filter pills)
- `--radius-md`: `6px` (Buttons, inputs, chart containers)
- `--radius-lg`: `10px` (Cards, modals, drawer panels)
- `--shadow-modal`: `0 16px 48px rgba(0, 0, 0, 0.65)` (Depth with offset, zero colored halos)

## 2. Information Architecture & Spatial Grid

1. **Primary Anchor (0–2s)**: Top Control Bar. Evaluators immediately see the green `100.0% Row Survival` badge and the prominent `RUN EVALUATOR TOUR` primary button.
2. **Secondary Core (2–10s)**: 4 KPI Cards. Failed Login Rate (34.59%), Critical EDR Alerts (800), Top Protocol (TCP), and High-Risk Insiders (48) with explicit formula footnotes.
3. **Tertiary Workspace (10–30s)**: Asymmetric 2/3 + 1/3 Visualization Grid (Hero 10-department failure trend on the left; Firewall action and EDR donut on the right).
4. **Deep Investigation (30s+)**: Threat Leaderboard table with click-to-inspect opening the multi-hop lateral movement blast radius drawer.

## 3. Anti-AI-Slop Manifesto (APP UI Rules)

1. **Zero Decorative Halos**: Absolutely no unmotivated glowing borders, radial spotlight gradients, or neon drop-shadows. Shadows must have vertical offset (`0 16px 48px rgba(0,0,0,0.65)`).
2. **High Data-Ink Ratio**: Every pixel must carry analytical meaning. Crisp `#21262d` hairlines separate metrics without bulky 3-column marketing cards.
3. **No Fluffy SaaS Copy**: Ban phrases like *"Unlock the power of cyber posture"*. All copy must be operational: `FORMULA: COUNT(status='FAILED') / COUNT(*) * 100`, `IMPOSSIBLE TRAVEL: DETECTED`.
4. **Browser Surface Theming**: Scrollbars, selection background, and input focus rings are explicitly themed from the palette:
   - Selection: `background: rgba(88, 166, 255, 0.25); color: #ffffff;`
   - Scrollbars: 6px width, `#30363d` thumb on hover, transparent track.
   - Focus ring: `2px solid #58a6ff` with `outline-offset: 2px`.

## 5. Responsive & Accessibility Specifications

### Viewport Breakpoints
- **Desktop (1440px+)**: Standard layout with 2/3 + 1/3 asymmetric chart grid and persistent 280px sidebar.
- **Tablet (1024px)**: 2-column stacked chart grid; threat table enables smooth horizontal scroll with sticky User ID column; touch targets maintain 44x44px minimum.
- **Mobile (768px)**: Single-column linear layout; modal transforms to bottom-sheet; sidebar collapses to top hamburger menu.

### Accessibility (WCAG 2.1 AA Compliance)
- **Keyboard Navigation**:
  - `Escape` key immediately closes open modals (`#soc-rescue-modal`) and drawers (`#threat-drawer`), returning focus to the triggering element.
  - Tab navigation is trapped within active dialogs (`aria-modal="true"`).
  - All interactive elements have visible `:focus-visible` outlines (`2px solid #58a6ff; outline-offset: 2px;`).
- **Screen Reader Semantics**:
  - Tables use proper `<thead>`, `<tbody>`, and `<th scope="col">` tags.
  - Modal dialogues carry `role="dialog"`, `aria-labelledby`, and `aria-modal="true"`.
  - Dynamic status areas declare `aria-live="polite"`.
